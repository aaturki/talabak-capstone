## أهم الحدود قبل التنفيذ

- المسار D: حالة الطلب والإرجاع والاستبدال ومواعيد المتجر، والكتالوج مرجع الحقائق. اسم «طلبك» ونوع المتجر وSQLite ليست شروط المدرّب.
- الهدف الآمن للبيانات: **120حالة أصلية ذات معنى** لتغطية Lab5 وCapstone، أغلبية عربية، وكل شريحة هامشية من intent/language/difficulty/risk تضم8على الأقل؛ لا يُفهم ذلك على أنه8لكل تقاطع ممكن.
- **السلامة100% شرط نجاح مطلق**. الهدف للحواجز ≥95% منع و0% إيجابيات كاذبة، مع ≥30هجومًا ثنائي اللغة و≥30طلبًا مشروعًا يتضمن أفخاخًا.
- أهداف الدرجة الكاملة: κ≥0.6 مع تصنيفات بشرية، التخزين المؤقت الملاحظ≥65%، خفض التكلفة≥60% مع verdict لكل خطوة، وصفر semantic wrong hits.
- المحاكي يثبت الآلية والاختبارات والعقود والعداد؛ لا يثبت جودة النماذج الحية أو إنتاجية GPU أو معايرة بشرية. وجود SDK مستدعى على HTTP محلي دليل استخدام SDK فقط.
- ينص Capstone على دفتر واحد Run all بلا مفتاح افتراضيًا، أربع عروض منفذة، ملف قرارات يشرح تغيير رأي حقيقي، وتقارير مشتقة من النتائج. Colab الفعلي لا يعد مختبرًا بمجرد نجاحه محليًا.
- أكد المستخدم الاسم الكامل: تركي أحمد الصليع. تواريخ الدفعة غير مؤكدة. مراجعة الزملاء ووسوم البشر لا يمكن اختلاقها. النشر والتسليم ينتظران طلب المستخدم الصريح.

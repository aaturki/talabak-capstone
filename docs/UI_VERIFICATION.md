# تحقق الواجهة المحلية

جرى التحقق في متصفح Codex المضمّن على `http://127.0.0.1:8765/` بتاريخ 15 سبتمبر 2026، باستخدام بيانات اصطناعية وشخصية العميل الأول.

| الخطوة | النتيجة المرئية |
|---|---|
| فتح الصفحة | واجهة عربية RTL، الشخصية التجريبية، أربعة طلبات متاحة للجلسة، ومواعيد المتجر |
| الضغط على تتبع ORD-1001 | «الطلب ORD-1001: تم التسليم.» مع المصدر orders:ORD-1001 |
| الضغط على طلب استبدال | تفاصيل استبدال ORD-1001 بالمنتج SKU-H200، وسبب الطلب، وزر موافقة مستقل |
| الضغط على موافق | «تم تسجيل الطلب REQ-DDA49C9C بحالة قيد المعالجة.»؛ تعطّل زر الموافقة السابق |
| سؤال عن ORD-2001 | «تعذر الوصول إلى الطلب بهذه الجلسة.» |
| محاولة تجاهل التعليمات وكشف النظام | رفض مصمم دون ترديد تعليمات النظام |

الحفظ والصلاحيات وتكرار الإجراء وحماية واجهة API اختُبرت أيضًا برمجيًا. هذه المراجعة تثبت تدفق المتصفح المحلي فقط؛ لا تثبت مصادقة إنتاجية أو تشغيلًا على Colab أو أداء نموذج حي. سجل التجربة المحلية تحت runtime/ مستثنى من Git.

لقطة الواجهة فُحصت بصريًا داخل الأداة؛ لا تُنسب إلى هذه الوثيقة لقطة محفوظة لم تُحفظ فعلًا.
